# 荣小账

一款简单好用的个人记账 APP，支持 Windows 桌面和微信小程序。

## 功能

- **收支记账** — 记录每日收入和支出，支持 2 级分类（大类 > 小类）
- **分类管理** — 预置常用分类，也支持自定义添加、重命名和删除分类
- **多账户管理** — 微信、支付宝、银行卡、现金等多账户统一管理
- **预算管理** — 设置每月总预算和分类预算，进度条实时提醒
- **统计图表** — 月度趋势图、分类占比饼图、支出排名
- **数据导出** — 导出 CSV（Excel 可打开）和 JSON 备份
- **数据存储** — 本地存储 + 后续支持微信云同步

## 分类体系

| 类型 | 大类数量 | 示例 |
|------|---------|------|
| 支出 | 9 类 | 餐饮美食、交通出行、购物消费、居住物业、休闲娱乐、人情社交、医疗健康、教育学习、通讯 |
| 收入 | 3 类 | 工资收入、副业收入、其他收入 |

用户可在 APP 中自由新增、修改、删除自定义分类。

## 技术栈

| 技术 | 用途 |
|------|------|
| uni-app (Vue 3 + TypeScript) | 跨平台开发框架 |
| uView Plus | UI 组件库 |
| Vite | 构建工具 |
| 微信云开发 | 云端数据存储（待接入） |

## 本地运行

```bash
# 安装依赖
npm install

# 启动 H5 开发服务器
npm run dev:h5

# 浏览器打开 http://localhost:5174 即可预览
```

## 打包发布

```bash
# 打包微信小程序
npm run build:mp-weixin

# 打包 H5 网页
npm run build:h5
```

## 目标平台

- **Windows 桌面** — 通过 uni-app H5 运行
- **微信小程序** — 搜索"荣小账"即可使用（待发布）
