# 微信小程序：大表格导入与收支柱状图

用户已选择：自动识别 Excel，必要时手动对应列；收支趋势改为并排柱状图。沿用本地 SheetJS，不新增收费 API 或小程序插件。

## 导入行为

- 文件支持 xlsx/xls/csv、20MB，单个工作表最多 10000 条账单，覆盖用户的 5000 条表格。工作表可选，不再要求固定列名或前 20 行内出现表头。
- 通过常见账单表头别名、数据类型和收支值评分，识别日期、金额、收支及可选字段。支持收入支出分列、带正负号金额和常见日期格式。不能确定的字段由用户调整列对应和数据起始行；缺失的财务事实不得猜测。
- 先转换成统一账单结构并预览，显示原始行号、无效原因和疑似重复。公式不执行；明确失败/关闭/不计收支的交易跳过。完整表格不传至大模型。
- 预览每页 50 行，跨页勾选互不影响；全选操作可作用于整个文件。所有金额合计按分累加。保存开始后锁定列对应，避免同一行重试时内容发生改变。
- 新后端每批最多 100 条，原子提交并按稳定 import_key 防重复，提交后再更新预算缓存。前端按批显示进度，可暂停并继续。
- 旧后端仅在 404/405 时退回逐笔保存；所有行的编号兼容旧后端三位尾号限制。网络错误后保留未确认行及同一编号，重试不重复写入。界面明确显示实际完成数量。
- 不把 5000 条逐笔插入全局账单列表，完成后通过原有页面读取最新账单。

## 图表

每月收入和支出并排柱子，收入绿、支出红，金额提示保留精确值，微信原生 Canvas 支持保持不变。

## 验证

真实 xlsx/xls/csv 测试包含 5000/10000 行、延后表头、银行分列、符号金额、无表头手动映射、工作表选择、无效日期/金额/公式/重复。验证分页勾选、暂停续传、批次重试、旧接口回退；后端验证权限、幂等、余额、事务回滚。最后在微信开发者工具验证图表和导入页，不向真实账本写入测试数据。
