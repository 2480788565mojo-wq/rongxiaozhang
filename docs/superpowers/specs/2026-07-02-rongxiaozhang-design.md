# 荣小账 — 产品设计文档

## 1. 项目概述

| 项目 | 内容 |
|------|------|
| APP名称 | 荣小账 |
| 类型 | 个人记账工具 |
| 目标平台 | Windows桌面 + 微信小程序 |
| 目标用户 | 全国微信用户（可通过小程序搜索使用）|
| 数据存储 | 云端同步（微信云开发）|

---

## 2. 技术架构

### 2.1 整体架构

```
┌─────────────────────┐     ┌──────────────────┐
│  微信小程序端        │     │ Windows桌面端      │
│  (uni-app编译)       │     │ (uni-app +         │
│                      │     │  Electron打包)     │
└────────┬────────────┘     └────────┬───────────┘
         │                           │
         └──────────┬────────────────┘
                    │ 同一套代码
         ┌──────────▼────────────────┐
         │    uni-app (Vue3 + TS)     │
         │    第三方UI组件库           │
         │    图表库                  │
         └──────────┬────────────────┘
                    │ 云函数调用
         ┌──────────▼────────────────┐
         │    微信云开发              │
         │  ├─ 云数据库 (5个集合)    │
         │  ├─ 云函数 (统计/导出)    │
         │  └─ 云存储 (导出文件)     │
         └─────────────────────────────┘
```

### 2.2 技术栈详情

| 层 | 技术 | 说明 |
|------|------|------|
| 前端框架 | uni-app (Vue3) | 一套代码编译到多个平台 |
| 开发语言 | TypeScript | JavaScript的超集，更规范的代码 |
| UI组件库 | 待用户选择 | 提供现成的界面组件，加速开发 |
| 图表库 | 待用户选择 | 用于统计页面图表渲染 |
| 后端 | 微信云开发 | 腾讯云提供的Serverless服务 |
| 数据库 | 云数据库 | 腾讯云文档型数据库 |
| 云函数 | Node.js | 编写后端逻辑 |
| 桌面打包 | Electron | 将H5打包为Windows桌面应用 |

### 2.3 微信云开发免费额度

| 资源 | 免费额度 | 个人记账预估用量 |
|------|---------|----------------|
| 数据库存储 | 2GB | ✅ 绰绰有余 |
| 云函数调用 | 50万次/月 | ✅ 绰绰有余 |
| CDN流量 | 5GB/月 | ✅ 绰绰有余 |

> 个人记账使用量很低，免费额度完全够用，基本不会有费用。

## 3. 功能页面设计

### 3.1 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页仪表盘 | pages/index/index | 本月收支总览、预算进度、最近记录 |
| 记账页 | pages/add/index | 记录一笔收支 |
| 账单列表 | pages/bills/index | 时间线排列记录 |
| 统计页 | pages/stats/index | 图表展示 |
| 账户管理 | pages/accounts/index | 管理账户 |
| 预算管理 | pages/budget/index | 预算设定与进度 |
| 设置页 | pages/settings/index | 数据导出、关于 |

### 3.2 底部导航设计

```
┌──────────┬──────────┬──────────┬──────────┐
│   首页   │   统计   │  (＋)    │   账单   │   我的
│          │   📊    │  记账    │   📋    │   👤
└──────────┴──────────┴──────────┴──────────┘
```

- 中间"＋"记账按钮为大号突出设计
- 未选中时图标为灰色，选中时为主题色

### 3.3 各页面详细说明

#### 3.3.1 首页仪表盘

顶部区域：
- 本月总收入 / 本月总支出 / 本月结余
- 相比上月的增减百分比

中部区域：
- 预算进度条（例如"餐饮预算 还剩 ¥800/¥2000"）
- 有颜色标识：正常（绿）/ 超80%（黄）/ 超100%（红）

底部区域：
- 最近5条记账记录
- 点击可查看详情或编辑

#### 3.3.2 记账页

表单字段：
| 字段 | 类型 | 说明 |
|------|------|------|
| 类型 | 切换按钮 | 支出 / 收入 |
| 金额 | 数字输入 | 人民币元，支持两位小数 |
| 分类 | 选择器 | 先选一级大类，再选二级小类 |
| 账户 | 选择器 | 从用户设置的账户中选择 |
| 日期 | 日期选择 | 默认为今天，可修改为过去日期 |
| 备注 | 文本输入 | 选填 |

#### 3.3.3 账单列表

- 按月分组显示
- 每组显示月份、当月总收支
- 每条记录显示：图标、分类名、金额、账户名、备注
- 支持按月份筛选（顶部下拉选择）
- 支持按分类筛选（筛选按钮弹窗选择）
- 下拉加载更多历史记录

#### 3.3.4 统计页

包含多个统计卡片：

- **月度趋势折线图**：展示最近12个月每月支出趋势
- **支出分类饼图**：当月各类支出占比，可点击查看明细
- **收支对比柱状图**：每月收入vs支出对比
- **本月支出TOP5**：花钱最多的5个分类

右上角可切换查看月份。

#### 3.3.5 账户管理

- 展示所有账户列表，每个账户显示名称、图标、余额
- 点击账户可编辑名称和图标
- 底部"添加账户"按钮
- 账户类型：现金、银行卡、微信钱包、支付宝、其他

#### 3.3.6 预算管理

- **每月总预算**：设一个数字，显示已用百分比
- **分类预算**：对选中的一级分类单独设置预算
- 每个分类预算显示进度条
- 超预算时给出提示

#### 3.3.7 设置页

| 功能 | 说明 |
|------|------|
| 数据导出CSV | 选择月份范围，导出Excel格式 |
| 数据导出PDF | 生成带图表的PDF报表 |
| 清除数据 | 清除所有记账数据（需确认） |
| 关于 | 版本号、免责声明 |

## 6. 数据流说明

### 记账流程

```
用户点击"＋"按钮
  → 弹出记账页
  → 填写/选择：类型、金额、分类、账户、日期、备注
  → 点击"保存"
  → 调用云函数写入 bills 表
  → 同步更新 accounts 表（余额变动）
  → 返回首页，刷新仪表盘数据
```

### 统计查询流程

```
用户进入统计页
  → 云函数聚合查询 bills 表
  → 按分类分组统计金额
  → 按月统计趋势数据
  → 返回前端渲染图表
```

### 数据导出流程

```
用户选择"导出CSV/PDF"
  → 云函数查询指定月份所有账单
  → CSV：生成CSV文本 → 存入云存储 → 返回下载链接
  → PDF：生成PDF文件 → 存入云存储 → 返回下载链接
  → 小程序端：使用 wx.downloadFile + wx.openDocument 打开
```
