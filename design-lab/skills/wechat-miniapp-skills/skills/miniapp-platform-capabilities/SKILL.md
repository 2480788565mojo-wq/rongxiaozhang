# Mini App Platform Capabilities

## Goal

正确接入微信小程序平台能力，并把“API 调通”升级为“权限、兼容、失败、降级和隐私都完整”。

## Capability Checklist

集成任何平台 API 前确认：

- 当前基础库/框架是否支持。
- 是否需要用户授权或隐私声明。
- 开发者工具与真机行为是否不同。
- 是否需要 HTTPS 合法域名或业务域名配置。
- 拒绝、取消、系统不支持时如何降级。
- 是否需要在 `app.json` / 页面配置 / project config 增加声明。

## Common Capabilities

### Location

- 区分“获取当前位置”和“选择地点”。
- 经度纬度只作为数据，不自己假设业务地址正确。
- 被拒绝时允许手动输入/选择（业务允许时）。

### Camera / Album / Scan

- 用户触发后再请求。
- 校验文件类型、大小、数量。
- 扫码结果属于不可信外部输入，需要格式与业务校验。

### Share

- 明确分享路径和参数。
- 不在分享参数里泄露敏感数据。
- 被分享者打开时校验资源是否仍存在且有权限访问。

### Subscription Message

- 在用户能够理解用途的业务时机请求。
- 不把订阅结果当作消息一定送达。
- 服务端维护发送资格与模板参数。

### WebView

- 配置业务域名。
- 设计小程序与 H5 的边界和返回路径。
- 外链参数和消息通信需校验。

### Files / Media

- 区分临时路径、持久路径、远程 URL。
- 处理下载失败、保存失败、权限和空间问题。

## Compatibility

平台能力在开发者工具、iOS、Android、不同微信版本上可能有差异。涉及相机、定位、蓝牙、文件、键盘、WebView 的功能应安排真机验证。

## Graceful Degradation

平台能力不可用时，优先提供：

- 手动输入
- 稍后重试
- 设置入口
- H5/客服/其他渠道（仅在产品允许时）

不要让非核心能力失败导致整个页面不可用。

## Anti-Patterns

- 只在开发者工具验证平台能力。
- 用户尚未触发功能就批量请求权限。
- 扫码/分享参数直接作为可信业务参数使用。
- 权限被拒绝后页面陷入死路。
- 忽略基础库版本或配置要求。
