# editorial

## Character

以阅读和内容结构为中心，强调标题、摘要、正文、元信息和图片的节奏。

## Tokens

- Page: 阅读友好的浅色背景。
- Text: 主正文对比度高，辅助信息更克制。
- Radius: 8–16rpx，减少视觉噪音。
- Shadow: 基本不用。
- Typography: 标题层级更丰富，正文行高更舒适。
- Spacing: 段落与 section 节奏优先于卡片边界。

## Components

- Content card：可无边框、无阴影。
- Meta row：时间、作者、标签弱化。
- Image：保持稳定比例与说明文字。
- Action bar：收藏、分享、目录等不抢正文注意力。

## Avoid

正文每段卡片化、装饰性图标过多、过窄行高和过密信息。
