# soft-card

## Character

柔和、亲和、易接近，以圆角 surface 和轻微层级感组织内容。

## Tokens

- Page: 淡色背景。
- Surface: 白色或轻微品牌染色。
- Radius: 20–32rpx。
- Shadow: 很轻，只用于浮层或重点卡片。
- Spacing: 16 / 24 / 32rpx。
- Accent: 可使用低饱和辅助色，但主操作色保持单一。

## Components

- Card：圆角明显，但不要所有文字都装进独立卡片。
- Tags：柔和底色 + 清晰文字。
- Inputs：大点击区，表单可按 section card 分组。
- Empty state：可带轻量插图，但不要挤压主要行动。

## Avoid

“卡片套卡片”、所有按钮都做 pill、过多 pastel 颜色。
