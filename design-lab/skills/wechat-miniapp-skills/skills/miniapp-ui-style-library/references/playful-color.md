# playful-color

## Character

活泼、年轻、有品牌记忆点，但核心任务和状态必须保持清楚。

## Tokens

- Page: 可有轻度品牌背景。
- Accent: 1 个主色 + 1–2 个受控辅助色。
- Radius: 20–32rpx。
- Typography: 可提高标题个性，但正文保持系统可读字体。
- Illustration: 可用于 onboarding、empty、活动场景。

## Components

- Button：主 CTA 视觉明确。
- Card：可有品牌色块，但不牺牲信息层级。
- Badge / progress：可更有表现力。
- Feedback：成功、奖励、完成动作可提供轻度动效。

## Avoid

彩虹配色、每个模块一个颜色、动效阻塞操作、正文使用难读的装饰字体。
