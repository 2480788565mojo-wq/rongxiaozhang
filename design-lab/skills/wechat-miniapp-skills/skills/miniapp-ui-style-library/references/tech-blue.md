# tech-blue

## Character

理性、清晰、现代，适合数据、AI、效率和复杂状态，但不等于“霓虹赛博”。

## Tokens

- Page: 浅冷灰或中性背景。
- Surface: 清晰分层。
- Accent: 蓝 / 青方向的单一主色，可由品牌覆盖。
- Radius: 12–20rpx。
- Shadow: 低层级。
- Border: 可比其他风格更常用细边框表达结构。

## Components

- Status / metrics：数字与状态层级明确。
- Input / command：强调输入焦点和执行结果。
- Cards：适合信息块，但要控制数量。
- Charts：优先可读性，不用多色装饰。

## Avoid

默认深色、霓虹发光、蓝紫渐变遍地、把所有 AI 功能做成聊天气泡。
