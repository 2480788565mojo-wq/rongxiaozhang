# wechat-clean

## Character

中性、清楚、可信，优先让用户感觉“这是一个自然的小程序界面”，而不是营销网页。

## Tokens

- Page: 偏白或轻灰背景。
- Surface: 白色为主。
- Text: 深灰主文案，中灰辅助文案。
- Brand: 单一主强调色，品牌已有颜色时覆盖。
- Radius: 12–20rpx 为主。
- Shadow: 尽量不用；必要时只做低层级阴影。
- Spacing: 16 / 24 / 32rpx 形成稳定节奏。

## Components

- Primary button：实心、高对比、清晰动词。
- Secondary button：浅底或描边，不与主按钮竞争。
- Card：更多依赖背景差与间距，不依赖重阴影。
- List：分组和分隔清楚，点击区域整行可点。
- Form：标签、值、帮助和错误层级明确。

## Avoid

大面积 banner、复杂装饰、过度卡片化、网页式页脚。
