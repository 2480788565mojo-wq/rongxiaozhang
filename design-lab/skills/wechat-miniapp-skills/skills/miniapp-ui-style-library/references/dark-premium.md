# dark-premium

## Character

沉浸、克制、高对比，适合明确需要深色体验的展示型页面。

## Tokens

- Page: 深灰黑而非绝对纯黑优先。
- Surface: 至少 2 个深色层级。
- Text: 主要文字高对比，辅助文字降低亮度。
- Accent: 1 个高辨识品牌色。
- Radius: 12–24rpx。
- Shadow: 用 surface / border / blur 层级表达，不堆重黑阴影。

## Components

- Image / video：可成为主视觉。
- Bottom action：与系统安全区明确分层。
- Input：必须有清楚边界和焦点态。
- Modal：避免与背景融为一体。

## Avoid

纯黑+纯白大面积刺激、灰度层级不足、低对比小字、为“高级”滥用金色和玻璃拟态。
