# utility-dense

## Character

高信息密度、高频操作、低装饰，以效率、扫描速度和状态识别为目标。

## Tokens

- Page: 中性浅背景。
- Surface: 分区边界清晰。
- Radius: 8–16rpx。
- Shadow: 默认不用。
- Spacing: 8 / 16 / 24rpx，避免无意义大留白。
- Typography: 正文和辅助文字层级紧凑但可读。

## Components

- List：优先高扫描效率，主信息和状态在固定位置。
- Filter：常用筛选靠近结果，不做复杂装饰面板。
- Form：字段密度较高时按任务分组，不压缩点击区。
- Actions：常用动作直接可见，危险动作保持明确确认。

## Avoid

为了“效率”把点击区、字号和间距压到不可用；照搬桌面表格；状态只靠颜色。
