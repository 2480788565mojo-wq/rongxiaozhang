# minimal-light

## Character

大量留白、克制装饰、清晰排版。适合内容不拥挤、品牌需要呼吸感的页面。

## Tokens

- Page / Surface: 接近统一浅色背景。
- Text: 主要依赖字号、字重和留白建立层级。
- Accent: 只保留 1 个品牌强调色。
- Radius: 8–16rpx。
- Shadow: 默认无阴影。
- Spacing: 比其他风格更宽松，section 之间明显分离。

## Components

- Button：轮廓简单，避免胶囊按钮滥用。
- Card：优先“无卡片容器”，用排版分组。
- Image：可以承担较大视觉权重。
- Navigation：减少不必要图标和说明。

## Avoid

用空白掩盖信息架构问题；重要任务入口过于隐蔽。
