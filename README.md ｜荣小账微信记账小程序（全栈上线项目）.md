## 📌 项目简介

荣小账是一款轻量化个人记账微信小程序，支持日常收支记录、账单分类、数据统计等功能。前端基于 UniApp 跨端开发，后端基于 FastAPI 高性能异步接口开发，搭配 MySQL 实现数据持久化，完整实现了「小程序前端 \+ 后端接口 \+ 公网服务器部署 \+ 合规上线」的完整互联网项目闭环。

## 🛠 技术栈

- **前端**：UniApp、Vue3、微信小程序原生规范

- **后端**：Python、FastAPI、异步接口开发

- **数据库**：MySQL 8\.0

- **服务器**：腾讯云轻量应用服务器（Ubuntu）

- **部署架构**：Nginx 反向代理、SSL HTTPS 全站加密、Systemd 进程守护

- **合规资质**：域名 ICP 备案（已提交审核，满足小程序上线规范）

## 🌐 线上架构流程

微信小程序客户端发起 HTTPS 请求 → 公网 443 端口 → Nginx 解析 SSL 证书 → 反向代理转发至本地 127\.0\.0\.1:8001 FastAPI 后端 → MySQL 数据库读写数据 → 原路返回数据至小程序。

**安全设计**

- 后端仅监听本地 127\.0\.0\.1，不暴露公网端口，避免端口攻击

- 全站 HTTPS 加密传输，符合微信小程序强制安全规范

- Systemd 托管服务，实现开机自启、崩溃自动重启

- 域名完成 ICP 备案，合规可用于小程序真机上线

## ⚠️ 项目全程真实踩坑与解决方案（核心亮点）

本章节为项目**核心面试加分内容**，所有问题均为本人部署过程真实遇到、独立排查解决：

#### 1\. MySQL 无初始密码，无法登录 root 账号

问题：全新安装 MySQL8\.0 无默认密码，无法进入数据库。

解决：修改配置开启免密登录模式，重置 root 密码、刷新权限，恢复正常数据库登录。

#### 2\. MySQL 本地可登录、远程无法连接

问题：后端项目、外部设备无法远程连接数据库，提示权限拒绝。

解决：授权 root 全网主机访问权限，适配 MySQL8\.0 修改密码加密规则，刷新权限彻底解决远程连接问题。

#### 3\. 数据库中文、表情乱码存储失败

问题：数据表编码不统一，中文、Emoji 表情写入报错、乱码。

解决：统一全局、数据库、数据表编码为 utf8mb4，适配小程序全部业务数据。

#### 4\. Nginx 反向代理 502 网关错误

问题：Nginx 代理端口与后端 Uvicorn 启动端口不一致（8000/8001 端口冲突），链路中断。

解决：统一全站端口为 8001，同步 Nginx 代理配置，重启服务恢复正常链路。

#### 5\. HTTPS 证书域名不匹配报错

问题：使用 IP 本地测试 HTTPS 接口，证书域名不匹配校验失败。

解决：公网使用备案域名正式访问，本地测试跳过证书校验，区分测试环境与生产环境规范。

#### 6\. 未备案域名被腾讯云网关拦截

问题：服务器、服务、配置全部正常，公网访问直接拦截。

解决：完成 ICP 备案流程，合规解除云厂商拦截，满足小程序上线硬性条件。

#### 7\. 后端端口直接暴露公网，存在安全隐患

问题：开发环境 0\.0\.0\.0 全网监听，后端直接暴露公网可被攻击。

解决：生产环境改为 127\.0\.0\.1 本地监听，通过 Nginx 反向代理隔离后端真实端口，提升服务安全性。

#### 8\. SSH 关闭后端服务直接中断

问题：终端运行项目，断开 SSH 服务直接停止，无法线上常驻。

解决：使用 Systemd 托管进程，实现开机自启、崩溃自动重启、后台常驻，适配生产环境。

#### 9\. FastAPI 根路径 404/400 误报故障

问题：访问根路径报错，误以为部署故障。

解决：根路径未配置业务接口属于正常情况，前端统一携带 /api/v1 基础路径请求，精准匹配后端路由。

#### 10\. ICP 备案表单违禁词驳回风险

问题：初始填写包含「小程序、平台、系统」等违禁词，无法提交。

解决：严格遵循个人备案规范，修改为纯技术项目描述，规避敏感词汇，顺利提交审核。
